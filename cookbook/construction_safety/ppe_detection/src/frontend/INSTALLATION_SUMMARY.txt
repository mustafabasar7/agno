============================================================
🔌 API ENTEGRASYONU
============================================================

REST API Endpoints:
   GET    /api/cameras           - Kamera listesi
   POST   /api/cameras           - Yeni kamera ekle
   PATCH  /api/cameras/{id}      - Kamera güncelle
   DELETE /api/cameras/{id}      - Kamera sil
   GET    /api/violations        - İhlal listesi
   GET    /api/statistics        - İstatistikler

WebSocket Events (Server → Client):
   - violation_detected       - Yeni ihlal tespit edildi
   - camera_status_changed    - Kamera durumu değişti
   - statistics_update        - İstatistikler güncellendi
   - camera_snapshot          - Yeni kamera görüntüsü

WebSocket Events (Client → Server):
   - handshake                - İlk bağlantı
   - ping                     - Heartbeat
