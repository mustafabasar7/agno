KULLANIM ÖRNEKLERİ
==================

1. Development:
   $ cp .env.example .env
   $ python -m config.config_validator
   $ python -m src.main --env development

2. Staging:
   $ python -m src.main --env staging --debug

3. Production:
   $ export ENVIRONMENT=production
   $ python -m src.main --env production

4. Custom:
   $ python -m src.main \
       --model-path models/custom.pt \
       --confidence 0.6 \
       --config custom.yaml
